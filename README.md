# Odikyu

Odikyu is a digital bodyguard on your phone that stops scams before money leaves your account — saving you from phishing, SMS fraud, and scam messages before it's too late.

## Features

- **Messages** — send and receive SMS in a clean, chat-style screen.
- **Protection** — toggle encrypted DNS over HTTPS (Cloudflare 1.1.1.1) so scam and phishing domains can't be looked up in the clear.
