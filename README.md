# Odikyu

Odikyu is a digital bodyguard on your phone that stops scams before money leaves your account — saving you from phishing, SMS fraud, and scam messages before it's too late.

## Features

- **Messages** — a clean, chat-style SMS screen. Set Odikyu as your **default SMS app** to take over all incoming and outgoing SMS (messages are stored in the system SMS store, so history survives restarts).
- **Phishing link warnings** — any message containing a link gets a warning card directly below it before you tap.
- **Protection** — toggle encrypted DNS over HTTPS (Cloudflare 1.1.1.1) so scam and phishing domains can't be looked up in the clear.
